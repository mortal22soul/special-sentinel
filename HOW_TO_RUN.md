# How to Run — Sentinel AML Detection

## Prerequisites

- Python 3.10+
- `uv` package manager (`pip install uv` or see https://docs.astral.sh/uv/)
- Azure OpenAI credentials (API key + endpoint from AI Foundry)
- Dataset files in `data/` (see **Data** section below)

## Environment Variables

Create a `.env` file in the project root (never commit this file):

```text
AZURE_OPENAI_API_KEY=<your-key>
AZURE_OPENAI_ENDPOINT=https://<resource>.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT_NAME=gpt-5.4-mini   # optional; defaults to gpt-5.4-mini
```

> **Note:** The endpoint must be the **base URL only** — do NOT include
> `/openai/v1` or any path suffix. The SDK constructs the full path automatically.

## Setup

```bash
# Install all dependencies (creates .venv automatically)
uv sync

# Copy .env template and fill in credentials
cp .env.example .env    # if .env.example exists, else create .env manually
```

## Data Pipeline (required once)

Run these two scripts in order before launching the app:

```bash
# Step 1: Parse pattern labels from HI-Small_Patterns.txt
# Output: data/pattern_labels.csv (3,209 labeled rows)
#         data/joined_labeled.csv (5M rows with pattern_type column)
# Runtime: ~15s
uv run python src/data/parse_patterns.py

# Step 2: Ingest into DuckDB
# Output: data/sentinel.duckdb (all tables + chronological splits)
# Runtime: ~45s on commodity hardware; ~4-6 GB RAM recommended
uv run python src/data/ingest.py
```

## Run the Streamlit UI (Primary Interface)

```bash
uv run streamlit run src/ui/app.py
```

Opens at `http://localhost:8501` by default.

**Example queries to try:**

- `Investigate Account 8000EBD30 for layering patterns`
- `Count total transactions over $10,000`
- `Show the currency distribution`
- `Check data quality — any missing values?`
- `Compute features for Account 8000EBD30`
- `What is the amount distribution on the training split?`
- `Show me the top 10 sender accounts`

## Run the Smoke Test (E2E validation)

Validates the full pipeline before using the UI — no UI required.
Requires Azure OpenAI credentials and an ingested DuckDB.

```bash
uv run python src/smoke_test.py
```

Expected output: 8/8 checks pass, including a full investigation query
and a multi-turn follow-up.

## Run the Routing Tests (CLI)

Tests supervisor routing correctness for 3 query types.

```bash
uv run python src/test_routing.py
```

## Run the Unit Test Suite

```bash
# Full test suite (42 tests, no Azure credentials needed)
uv run pytest tests/ -v

# Single test file
uv run pytest tests/test_routing.py -v
uv run pytest tests/test_features.py -v

# Single test function
uv run pytest tests/test_features.py::TestCycleDetection::test_simple_cycle_detected -v
```

Expected runtime: ~5s for all 42 tests.

## Train the Isolation Forest Model (optional)

The anomaly agent will prompt you to train the model if
`models/isolation_forest.pkl` doesn't exist. To pre-train:

```bash
# From the project root
uv run python -c "from src.agents.anomaly import train_isolation_forest; train_isolation_forest(split='train', sample_size=100_000)"
# Runtime: ~2-5 min; saves models/isolation_forest.pkl + models/scaler.pkl
```

Alternatively, from a Python REPL:

```python
from src.agents.anomaly import train_isolation_forest
train_isolation_forest(split="train", sample_size=100_000)
```

## Project Structure

```text
src/
  data/
    parse_patterns.py  -- parse HI-Small_Patterns.txt into labeled CSV
    ingest.py          -- load CSVs into DuckDB with chrono splits
  agents/
    data_query.py      -- Subagent 1: DuckDB SQL (query_database, get_schema)
    eda.py             -- Subagent 2: profiling (amount_profile, currency_distribution, ...)
    features.py        -- Subagent 3: feature engineering + networkx pattern detection
    anomaly.py         -- Subagent 4: Isolation Forest + rule-based hybrid scoring
    risk.py            -- Subagent 5: Low/Medium/High risk classification
    explain.py         -- Subagent 6: LLM-powered AML investigation summaries
  supervisor.py        -- orchestrator: routing, structured output, multi-turn memory
  ui/
    app.py             -- Streamlit chat dashboard (primary frontend)
  test_routing.py      -- CLI routing correctness tests
  smoke_test.py        -- E2E pipeline smoke test
tests/
  test_features.py     -- 26 unit tests for feature engineering and pattern detection
  test_routing.py      -- 16 unit tests for routing, schema, and tool registry
data/
  HI-Small_Trans.csv   -- raw transactions (5M rows, not committed)
  HI-Small_accounts.csv
  HI-Small_Patterns.txt
  joined_labeled.csv   -- generated by parse_patterns.py

  sentinel.duckdb      -- generated by ingest.py (not committed)
models/
  isolation_forest.pkl -- generated at runtime (not committed)
  scaler.pkl
```

## Troubleshooting

| Error                            | Fix                                                                     |
| -------------------------------- | ----------------------------------------------------------------------- |
| `No module named ...`            | Run `uv sync`                                                           |
| Azure 404 auth errors            | Remove `/openai/v1` suffix from endpoint in `.env`                      |
| Azure 401 / key errors           | Verify `AZURE_OPENAI_API_KEY` is current and not expired                |
| `sentinel.duckdb not found`      | Run `src/data/ingest.py` first                                          |
| `isolation_forest.pkl not found` | Run `train_isolation_forest()` from Python                              |
| Memory errors during ingest      | The DuckDB pipeline streams via `read_csv_auto`. Free at least 4 GB RAM |
| Streamlit port conflict          | Run `uv run streamlit run src/ui/app.py --server.port 8502`             |
